# 🎧 GAN-Based Speech Enhancement

This project uses a **Generative Adversarial Network (GAN)** to enhance noisy speech using a custom Streamlit interface.

> 🔊 Upload your noisy `.wav` file and get back an enhanced version instantly.  
> 💬 Optionally upload clean audio to compare PESQ, STOI, and SNR metrics.
